# Mashhad AI Studio — خلف الحقيقة

لوحة عربية RTL أولية لإدارة أفكار الحلقات وذاكرة القصة ومقاييس الصفحة وتقارير PDF. **ليست بعدُ نظام نشر تلقائي مكتملًا**.

## تشغيل محلي

- يتطلب Python 3.11 أو أحدث.
- شغّل `./start.sh` على Linux/macOS، أو أنشئ بيئة Python وثبّت `requirements.txt` يدويًا على Windows.
- افتح `http://127.0.0.1:8000`.
- انسخ `.env.example` إلى `.env` وأضف الأسرار محليًا فقط عند الحاجة.

## تشغيل باستخدام Docker

```sh
docker build -t mashhad-ai-studio .
docker run --rm -p 8000:8000 -v "$PWD/data:/app/data" --env-file .env mashhad-ai-studio
```

## ما هو موجود

- لوحة عربية RTL متجاوبة.
- قاعدة SQLite لحفظ الحلقات، ذاكرة القصة، المقاييس وسجل النشاط.
- واجهات CRUD للحلقات والمقاييس.
- توليد نص اختياري عبر Mistral عند إعداد `MISTRAL_API_KEY`.
- اختبار قراءة محدود لبيانات Meta Graph API عند إعداد المعرف والرمز والصلاحيات.
- نقطة نهاية تقرير PDF: `/api/report.pdf`.
- فحص صحة النظام: `/api/health`.

## ما لم يكتمل أو لم يُتحقق منه

- لا ينشئ التطبيق ملفات فيديو فعلية؛ مزود فيديو غير مربوط.
- لا يوجد نشر تلقائي فعلي على فيسبوك ولا ردود تلقائية على التعليقات.
- لا يوجد تشغيل خلفي مضمون أو جدولة موثوقة للتقارير على الاستضافة المجانية؛ مهمة البريد اختيارية وتعتمد على استمرار العملية وإعداد SMTP.
- لم تُختبر مفاتيح المستخدم أو تكاملات خارجية فعلية.
- لم يُنشر التطبيق على عنوان عام.

## أمان مهم قبل النشر العام

هذا نموذج أولي غير مقوّى للاستخدام العام: لا تعرضه للإنترنت قبل إضافة تسجيل دخول، HTTPS، تحديد معدل الطلبات، أسرار آمنة وتخزين دائم. لا ترفع `.env` أو أي رموز إلى GitHub. لا تضع كلمات المرور أو رموز الوصول في المحادثة.

## الإعدادات الاختيارية

راجع `.env.example`. Mistral مخصص للنصوص وليس لتوليد الفيديو. تعطيل النشر الخارجي هو الوضع الافتراضي.
